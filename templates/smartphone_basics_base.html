Тренинг по кнопкам телефона

Используйте кнопки на боковой стороне телефона для выполнения заданий

Где находятся кнопки:

• Левая сторона: кнопки громкости

• Правая сторона: кнопка питания

Телефон выключен
Нажмите кнопку питания, чтобы включить телефон

Тренинг: Кнопки телефона

Выполните 3 простых задания с кнопками

1
Увеличение громкости

Задача: Нажмите 3 раза на кнопку увеличения громкости

Прогресс: 0 из 3 нажатий

ШАГ ЗА ШАГОМ:

1. Найдите левую сторону телефона
2. Найдите верхнюю кнопку (увеличение громкости)
3. Нажмите на эту кнопку 3 раза

Кнопка находится слева от черного телефона

2
Уменьшение громкости

Задача: Нажмите 2 раза на кнопку уменьшения громкости

Прогресс: 0 из 2 нажатий

ШАГ ЗА ШАГОМ:

1. Найдите левую сторону телефона
2. Найдите нижнюю кнопку (уменьшение громкости)
3. Нажмите на эту кнопку 2 раза

Это кнопка ниже кнопки увеличения громкости

3
Выключение телефона

Задача: Нажмите кнопку питания, чтобы выключить телефон

Статус: Телефон включен

ШАГ ЗА ШАГОМ:

1. Найдите правую сторону телефона
2. Найдите кнопку питания (обычно единственная кнопка справа)
3. Нажмите на кнопку питания 1 раз

После нажатия экран станет черным - это означает, что телефон выключен
